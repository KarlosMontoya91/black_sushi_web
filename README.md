# Black Sushi Asian Cuisine

Propuesta de sitio para Black Sushi, Santa Catarina, Nuevo León. La página es estática y funciona abriendo `index.html` o sirviendo la raíz del repositorio con cualquier servidor estático.

La base se tomó de [Shari en español](https://github.com/KarlosMontoya91/sushi_web/commit/922db2d7e45ab13aa72cb99f7b3806990d812ebc). La propuesta conserva la entrada animada, los pétalos, el movimiento de las cintas, el desplazamiento panorámico y las fotos que pueden arrastrarse. Se puede pausar el movimiento desde la portada.

## Información y material visual

- El [Instagram del restaurante](https://www.instagram.com/blacksushi_asiancuisine/) publica el 2x1 y enlaza a WhatsApp y [Soft Restaurant](https://delivery.softrestaurant.com.mx/restaurante/blacksushiasiancuisine#/menu). La carta, la disponibilidad y la operación del pedido se consultan con el restaurante o en su plataforma.
- La dirección y el horario publicado se consultaron en [Qué Comer](https://quecomer.com/places/black-sushi-asian-cuisine/) y [Restaurant Guru](https://es.restaurantguru.com/Black-Sushi-Asian-Cuisine-Santa-Catarina). Confirma el horario, los rollos incluidos y las condiciones del 2x1 con el restaurante antes de lanzar el sitio como oficial.
- Las fotos de la propuesta son recortes de la galería de [Black Sushi en Restaurant Guru](https://es.restaurantguru.com/Black-Sushi-Asian-Cuisine-Santa-Catarina). Para la publicación oficial, el restaurante puede confirmar el material visual o facilitar sus originales. El sello tipográfico es una propuesta visual.
